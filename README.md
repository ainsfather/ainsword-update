# Ain's Word 업데이트 배포용 브랜치 (dist)

이 브랜치에는 앱이 스스로 업데이트할 때 내려받는 파일만 있어요.

- `update.json` — 최신 버전 정보 (버전, 바뀐 점, 파일 주소, 크기, SHA-256)
- `AinsWord-<버전>.awu` — 암호화된 설치 파일 (앱만 풀 수 있어요. 직접 설치하는 파일이 아니에요)

앱(1.4.0 이상)은 설정 › 앱 정보 또는 홈 화면의 업데이트 버튼으로 이 파일을 받아 설치해요.
같은 서명 키로 만든 더 높은 버전만 설치되고, 학습 기록·단어장·스티커는 그대로 남아요.
