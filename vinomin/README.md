# Vinomin 업데이트 파일

이 폴더는 와인 기록 앱 **Vinomin**(`com.jym.wine`)의 앱 안 업데이트용이에요.
저장소 맨 위의 Ain's Word 파일, `hanja-rocket/` 의 한자 로켓 파일과는 따로 관리해요 (서로의 파일을 건드리지 않아요).

- `update.json` — 최신 버전 정보 (버전, 바뀐 점, 파일 이름, 크기, SHA-256)
- `Vinomin-<버전>.awu` — 암호화된 설치 파일 (앱만 풀 수 있어요. 직접 설치하는 파일이 아니에요)

앱은 설정 › 앱 정보 또는 홈 화면의 업데이트 알림으로 이 파일을 받아 설치해요.
같은 서명 키로 만든 더 높은 버전만 설치되고, 와인·기록·평점·사진은 그대로 남아요.
